# Примеры из пакета wooldridge (проверка OLS)

В учебнике Wooldridge **нет** готового дневного ряда «рекламный бюджет → продажи».
Ближайшие к рекламе/маркетингу наборы:

| Датасет | Суть | Роль «рекламы» | Роль Y |
|---------|------|----------------|--------|
| `vote1` | выборы в Конгресс США | `expendA` / `shareA` — кампанийные расходы | `voteA` — % голосов |
| `charity` | пожертвования (маркетинг) | `mailsyear` — рассылки в год | `gift` — размер дара |

## Проверка нашего движка

```bash
pip install wooldridge statsmodels
python3 scripts/export_wooldridge_examples.py
npx tsx scripts/verify_wooldridge.ts
python3 scripts/compare_wooldridge_statsmodels.py
```

Ожидаемый итог: коэффициенты и R² совпадают со **statsmodels** (расхождение β < 1e-6).

## Важно для UI

Эти датасеты — **поперечные срезы**, не временные ряды. Вставлять их в онлайн-форму
вместе с курсом доллара/Brent нельзя (даты синтетические). Они проверяют ядро OLS,
а не джойн с макрофакторами.
